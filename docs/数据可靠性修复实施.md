# 数据可靠性修复实施（2026-11-03）

用户明确要求修复上一轮审查的问题。本记录描述本地实际代码变更；没有把静态检查、测试代码存在或等待中的云端流程写成验证通过。

## 已修改的代码路径

1. **作息草稿与原子提交**：减少节次只改表单草稿；保存前列出将被移除的课程并确认，使用修改后的节次上限。`applyAcademicSettings` 在内存构造完整学期，裁剪周次、清理相关调停课、更新作息时间后统一提交。修改第一周时相关调课日期同步平移，保留记录 ID。保存失败回滚内存学期与选中状态。表单取消不调用存储删除方法。
2. **重复导入**：用相同科目、星期、节次与有效周次匹配已有安排，保留课程 ID、提醒开关、来源与颜色，因此调停课引用继续有效。单双周独立保留；周次不同不自动互相覆盖。完全重复的输入去重；同一身份但教师/教室相互矛盾时提示并跳过，不按数组先后偷偷选一份。预览绑定目标学期，写入前再次检查学期、周数和作息。写入失败留在预览页显示原因。
3. **备份与恢复**：确认文案明确覆盖本机全部学期，列出旧学期和新备份数量。破坏性修改前保留保护副本，正常数据副本为可再次导入的标准归档，可从设置导出；损坏或高版本原始载荷连同存储版本原样保留。副本失败即停止覆盖。恢复整体提交，失败回滚；SwiftData 保存失败执行 context.rollback。
4. **读取失败保护**：解码或校验失败进入只读保护状态，不展示默认样例冒充个人课表，不允许后续保存覆盖原记录。顶部提供前往设置的恢复入口，设置可导出原始字节；显式确认恢复备份并保留原文件后才允许写入。学期和课程破坏性操作同样遵守保护状态。
5. **同步比较**：规范化归档后比较业务内容，导出时间、App 版本和数组排序不再制造伪变更；旧载荷也走相同比较路径。相同内容不重复写云端。云端损坏或本机未校验时停止应用/覆盖；初始化失败回退同步开关。文案不把加入 iCloud 同步队列当作其他设备已经收到。
6. **教务解析**：展开 rowspan/colspan，处理跨节课程和内嵌表格；元数据节次不再混入课程名。嵌套 JSON 使用括号/字符串感知扫描，保留 weeks 数组与单双周文本。星期无法唯一确定时要求选择“周一对应 0／1”，不直接猜。范围遍历在分配内存前限制到学期周数，表格行列和嵌套层数亦有上限。
7. **组件跳转**：快照与深链带上学期 ID，先定位正确学期和课程。兼容旧路径链接，未知/删除课程给出提示并返回课表；不再无反馈。无课程时链接回今日页。
8. **空课表与考试学期**：有效的空学期和只有考试的学期允许备份和同步，避免删掉最后一门课后，删除状态无法写入归档。

上一轮考试编辑白屏、外观切换和设置卡片的本地改动均保留；没有关闭用户先前要求的演示模式，也没有擅自新增考试专属系统提醒。
