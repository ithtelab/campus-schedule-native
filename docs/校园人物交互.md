# 校园人物动作与课程卡交互

日期：2026-10-31。用户授权补充站起、坐下、拿书、放书、行走及课程点击联动。原有吸顶、地点/时间优先、日程三列和深色专用插画要求继续保留。

## 实现

- 男生/女生各一组 4×4 动作图集，实际身体、手臂、腿和书的位置变化。通过原生 SwiftUI 按动作序列播放，非整张图片上下晃动。
- 点人物执行建议动作；长按弹出原生菜单，可选择站起、坐下、拿书、放书、行走或舒展。
- 状态分为坐姿有书、坐姿空手、站姿空手、站姿有书。动作按当前状态衔接；行走先收书并起身，拿书/放书保持坐站状态，完成后回到稳定姿态。
- 已开始的动作不会因重复点击并发播放；离开活跃状态时取消并恢复稳定姿态；减少动态效果下直接切换最终姿态。
- 课程卡保持打开详情的行为，增加轻微按压缩放和原生触感请求；人物同步收书/起身准备上课，详情中可继续与同一人物交互。点击不改变课程完成状态，不修改课程、提醒或数据。
- 人物按钮与课程详情按钮分开，避免嵌套按钮导致误触。
- 插画保留自然黑发和衣物关系，浅色外轮廓兼容两种背景，不使用整图反色。

## 图集一致性

女生前 15 帧继续从原始图集读取，只有最后一帧从修正图集读取。最后一帧按用户要求保留棒球帽、长发、条纹长袖及帆布包，并采用左手扶右手手肘的肩臂拉伸姿态。

资源位于 `CampusArtwork.xcassets` 的 `CampusBoyActions`、`CampusGirlActions` 和 `CampusGirlStretchCorrection` 三个图集。修正图集只使用最后一格，避免重绘其余帧造成角色变化。它是手绘短动作序列，不是骨骼驱动或物理仿真。

## 验证

- 共享模块新增六项真实动作计划测试，连同现有十二项规则测试一起在 macOS 运行。
- 原生动作验证页调用与人物点击相同的播放器，检查两个角色的逐帧序列、最终状态、减少动态效果、重复请求和停止。
- 云端导出真实模拟器动作录屏 `campus-interactions.mp4`、动作证明 `campus-interaction-test.txt`，以及课程详情暗色截图。
- 程序触发的播放器检查不等同于真实手指触控、长按或真机触感验收。
- 当前新增交互尚待本轮云端编译、录屏及视觉检查，不沿用上一版 UI 的通过结论。

图像资源通过内置 image_gen 生成并定向修正，完整提示词见《校园人物动作素材说明》。
