# 课表 UI 设计规范 · 第四版

## 第四版：校园黑白手绘

当前以用户确认的校园手绘方向为准，覆盖下方历史版本中的“选中系统蓝”和课程分类色条方案。原生接入范围与验证状态见《校园手绘原生实施记录》。

- 内容采用黑白与少量中性灰层次，不使用彩色分类块、渐变、阴影或自绘玻璃。
- 手写字体只用于固定标题和少量校园短句；时间、教室、课程正文使用系统字体。
- 下一节/当前课程头随今日页滚动吸顶；地点和时间最大，其他信息降级。标题、教师等不得挤占地点与时间。
- “一天的安排”使用统一三列和相同间距：时间 → 课程/教室 → 状态。过去白底细线，当前关注课程反白，其他未来课程浅底；不再使用点阵或额外标签框。
- 插画不绘制额外地面线和基线，女生旁不得出现邻近人物/凳子碎片。人物区域与文字分开，大字体下主卡隐藏装饰人物。
- 人物只做小幅原生动画，遵守减少动态效果，退后台停止循环；不声称已完成逐帧角色动作。
- 深色模式反转插画墨色，正文使用系统语义前景/背景，原生系统控件和材质保持原生行为。

以下为第三版和更早记录，不代表当前配色或交付状态。

## 第三版：布局精简与组件分栏

2026-10-30，用户已授权实施《UI 灵感对比与优化建议》。本节是当前设计规范；下方第二版内容保留为历史范围与验证记录，其中“未持久化”等说明不代表当前第二批业务进度，当前进度见《第二批实施记录》。

- 原生导航、标签栏、工具栏继续使用系统外观；常规操作浅色黑、深色白，选中系统蓝。
- 周课表头部合并日期范围与课程数量，取消重复说明行；有隐藏周末课程时保留提示。
- 保留已有回到本周、五天/七天切换、固定星期表头、节次对齐、左右滑动切周和大字体列表。
- 课程块采用系统语义表面与低强度分类细色条，取消大面积分类色背景和今天的整列底色；今天日期继续使用蓝色选中标记。
- 课程名、教室为核心信息，五天视图较高的课程块底部补充开始时间；单节课程采用较少行数，完整信息在详情查看。
- 周网格节高 46pt，午间/晚间分隔 22pt；课块圆角 7pt。顶部切周按钮点击区域为 44×44pt。
- 今日主卡采用系统标题字级，展示课程、完整教室、起止时间；状态采用语义黑白灰，移除彩色状态胶囊与装饰色条。
- 今日统计压缩为一段可换行的小字，已结束课程采用紧凑透明行；不降低整行透明度影响可读性。
- 辅助功能大字体下，日期/时间及课程状态采用纵向排版，今日课程采用单列卡片，避免固定宽度时间轴挤压正文。
- 正在上课时，下一节地点明确且不同则提示换教室；地点未知时提示待确认。无课保持原生空状态。
- 小号桌面组件：状态、课程、教室、上/下课时间。中号：左侧当前/下一节，右侧后续最多两门，显示教室。
- 组件跨日使用明确的“明天”或月日；日期与时间均按校园时区计算。锁屏矩形优先时间、课程、教室；行内优先日期、时间和课程名。
- 组件只调整内容，不自绘系统桌面/锁屏外壳；系统着色与透明效果仍需宿主验收。

本轮使用固定演示数据与时间导出深浅色、七天、大字体、正在上课和长文本/单节课程截图。云端验证状态见《云端验证记录》，没有截图或编译结果时不将其视为已通过。

## 第二版历史记录

## 本轮范围

用户已批准重做今日页、周课表，增加手动添加课程、学期与作息设置页面。本轮完成界面及会话内演示交互，不包含持久化、真实通知、教务导入与云同步。

## 视觉基础

- 使用系统语义背景、系统字体与 SF Symbols，跟随深色模式。
- 内容以稳定的浅色或深色表面为主，玻璃效果交由原生导航、标签栏、工具栏与弹窗提供。
- 页面边距一般为 20pt，密集周课表为 12pt；列表卡片圆角 18pt，重点卡片 24pt，课表课程块 10pt。
- 选中状态使用系统蓝色；常规操作按钮、周次入口和前后切换箭头使用系统 primary 色，浅色黑、深色白，辅助文字保留系统 secondary 层级。课程分类颜色与选择状态独立，同时保留名称、地点与时间信息，不单靠颜色识别。
- 顶部更多、添加等图标按钮使用单色：深色模式白色、浅色模式黑色，不使用紫色强调；保留原生玻璃底。此为用户明确偏好。
- 坚持原生 iOS 27 控件与系统材质，不自绘标签栏、按钮外形或附加玻璃特效；颜色调整不替换系统控件。

## 页面与交互

### 今日

- 紧凑日期与学期标题，明确标注演示时间 09:41。
- 状态卡展示尚未结束的下一门课程，区分进行中与待上课；结束后展示完成状态。
- 展示当天课程数、剩余课程数、最晚下课时间。
- 时间线展示各课程，弱化已结束课程；点击打开课程详情。
- 固定使用演示第 8 周周一，不代表设备真实今日，不进行后台计时或通知。

### 周课表

- 默认五个工作日完整显示，菜单可切换七天；有周末课程时提供提示。
- 头部展示周次、日期范围和课程安排数量，支持选择周次、前后按钮与左右滑动切周。
- 星期与日期固定在网格上方，课程区域竖向滚动；左侧显示节次和开始时间，下午与晚间有分隔。
- 课程块只显示名称和简化地点，完整时间、教师在详情查看。
- 高亮演示周一，红线标记演示 09:41 在课表中的位置；不将示例时间伪装成设备真实时间。
- 辅助功能大字体下改用按天分组的课程列表；仍需后续实际辅助功能验收。

### 手动添加课程

- 提供课程名称、地点、教师、星期、起止节次、每周/单双周/指定周次和颜色。
- 名称不能为空，至少选择一个教学周；禁止同一星期、重叠周次与重叠节次的冲突课程。
- 添加后更新当前会话的演示数据，退出 APP 后不保留；不安排通知。

### 学期与作息

- 配置学期名称、第一教学周周一、总周数和十节课各自的起止时间。
- 使用原生日期/时间选择器；时间必须先后有序且不重叠。
- 保存后更新当前会话的日期与课程时间，取消不应用修改。
- 当前总周数范围为 8–30 周，以保留第 8 周演示场景；正式业务规则后续设计。
