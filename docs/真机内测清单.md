# 首轮 iPhone 内测

目标版本：`0.1.0 (4.1)`。测试包的上传、Apple 处理和内部测试资格分别记录在《TestFlight发布》；上传完成不代表这些测试已通过。

## 安装与本地数据

从本人收到的 Apple TestFlight 邀请进入安装，确认 TestFlight 显示目标版本。首次启动为空课表，不预置个人课程。设置学期与作息，手动添加当天课程，退出重开确认课程及设置仍保留。

添加、修改和删除课程，确认今日页、周课表和详情一致。测试调课与停课后，相关安排、提醒和组件内容是否更新。学校登录导入未接入，本轮不测试导入。

## 人物和布局

- 开启系统浅色、深色模式，检查人物黑发、帽子、衣袖及包的形态和轮廓；女生身份应一直一致。
- 课前提前量之外：首课前阅读，已上过课后的课间休息；进入提前量时准备。
- 前后教室明确不同，进入课前提前量后才行走；同教室或地点待定不行走；正在上课优先看书。
- 当天结束后收书、起身放松，再回到休息姿态。打开过去或其他未来课程不改变真实的当前课表阶段。
- 点击人物或关联课程，只得到当前阶段合理的回应；连点不会叠加动作。减少动态效果、切后台、回前台后姿态仍正确。
- 上下滚动确认下一节卡片吸顶，教室与时间清楚；测试长课程名、较大文字。

## 系统功能

在真机允许通知；分别测试上课提前量、下课提醒开关、单门课程关闭提醒，以及课程修改/删除后的提醒撤销。记录系统专注模式、静音和通知权限状态，以便解释送达差异。

实际添加桌面小号、中号和锁屏组件，核对当前与下一课程、跨日、空课、深浅色和点击跳转。共享组已在签名包中确认，跨进程读取与系统刷新仍需要此次真机验收。

灵动岛仅做现有行为观察：课前开始、上课状态、换教室提示、手动移除及下课结束。完整后台到点结束和多节自动衔接尚未完成，不将它们预先列为通过。

## 反馈

出现问题时记录：截图/录屏、发生时间、涉及课程及教室、版本号、是否切后台、系统通知/减少动态效果状态。可通过 TestFlight 的反馈入口或本聊天反馈。无需提供真实教务登录信息。
