# 本次课程：课堂入场券设计

2026-11-03，用户认为只读课程页过于素，并要求新的创意，不再复用相同人物和卡片。

## 本轮设计

- 保留原生导航和完成按钮。课程入口仍为独立只读页面，不加入编辑、调课或删除操作。
- 页面以“课堂入场券”为视觉比喻：手写标题、平涂教室门牌、票据虚线与手撕下缘。名称、教室、日期和上下课时间均来自实际课程安排。
- 新绘制黑板、课桌、课本、书包和校园小猫组成的教室小场景，使用原生向量绘图，不引用已有女生或男生图集。课前保留黑板笔记、课中补充粉笔线条且小猫闭眼、结束后合书并抬尾，完全由所点课程的时间状态决定。
- 新纸飞机图标沿课程时间轨道移动，明确标注“本次上课进度”和未开始／剩余分钟／已结束；不是教室路线或导航，不虚构距离。
- 保持单色，无渐变与投影；资源随语义黑白配色适配深浅色。辅助功能大字体隐藏场景装饰，时间纵排，优先保证课程信息可读。

## 实施范围

`CourseNowView.swift` 为新的票据布局；`CourseSessionArtwork.swift` 为本页专属向量图、票据轮廓和纸飞机。没有实现人物选择、装饰商店、教师模式或纪念事件功能。

本地工程生成与配置检查通过；新增绘图及排版尚待本轮 macOS 原生编译和真实截图检查。此前简版页面的验证不作为本次新布局已经通过的证据。

首轮新设计任务 `41640176070` 通过原生编译、326 项规则测试和入口 UI 自动化。人工截图检查发现黑板的绘图子路径缺少起点、标题字体子集只有 36 个字符，导致三角形黑板和部分文字回退系统字体。已修正路径，并从 [Google Fonts 原字体](https://github.com/google/fonts/tree/main/ofl/mashanzheng) 保留全部旧字符、补充新标题字符，子集覆盖 40 个字符；原许可证继续随包保留。`scripts/add-campus-heading-glyphs.py` 可从同一原字体重新生成子集，普通构建不依赖该脚本。
