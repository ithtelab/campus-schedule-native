# 本次课程：课堂入场券设计

2026-11-03，用户认为只读课程页过于素，并要求新的创意，不再复用相同人物和卡片。

## 本轮设计

- 保留原生导航和完成按钮。课程入口仍为独立只读页面，不加入编辑、调课或删除操作。
- 页面以“课堂入场券”为视觉比喻：手写标题、平涂教室门牌、票据虚线与手撕下缘。名称、教室、日期和上下课时间均来自实际课程安排。
- 新绘制黑板、课桌、课本、书包和校园小猫组成的教室小场景，使用原生向量绘图，不引用已有女生或男生图集。课前保留黑板笔记、课中补充粉笔线条且小猫闭眼、结束后合书并抬尾，完全由所点课程的时间状态决定。
- 新纸飞机图标沿课程时间轨道移动，明确标注“本次上课进度”和未开始／剩余分钟／已结束；不是教室路线或导航，不虚构距离。
- 保持单色，无渐变与投影；资源随语义黑白配色适配深浅色。辅助功能大字体隐藏场景装饰，时间纵排，优先保证课程信息可读。
