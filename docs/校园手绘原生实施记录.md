# 校园手绘风格接入原生 APP

日期：2026-10-30。用户已明确授权本轮接入原生 APP，并要求修复女生旁边残线、重排“一天的安排”。

## 本轮实现

- 下一节/当前课程使用 SwiftUI `LazyVStack` 的固定 Section 头，在今日页滚动时保留。
- 教室和起止时间采用最大字号；课程名、状态和其他说明作为辅助信息。
- 日程统一时间列、课程/教室列、状态列的对齐、内边距、圆角。取消点阵纹理、单独状态框等干扰，只保留黑白与浅灰填充层次。
- 浅色白底黑字，深色黑底白字；原生导航、标签栏、表单和弹窗继续交给系统。全局选中强调改为单色，覆盖先前的系统蓝方案。
- 校园人物重新生成并清理，三个姿态分别隔离显示；女生图中没有相邻凳子碎片或额外地面基线。主内容仅在适当留白使用人物、课本与手绘下划线。
- 人物动效为轻微位移/倾斜，非逐帧肢体动作。减少动态效果开启或 APP 不活跃时显示静态人物。
- 深色模式已改为专用人物资源，保留黑头发、黑裤子与白色卫衣等原始关系；移除整图反色，外轮廓补充浅色细线用于黑底辨识。
- Ma Shan Zheng 开源手写字体仅用于固定标题；正文、时间与教室使用系统字体。字体子集 36 个字符，许可证随项目保存，不用于任意用户输入。
- 本地保存、课程实例、通知与实时活动规则沿用现有实现；课程历史颜色字段保留兼容，当前界面采用单色，不再提供彩色选择。

## 资源与打包

- `CampusSchedule/Resources/CampusArtwork.xcassets`：透明校园人物图集，作为主应用资源编译。
- `CampusSchedule/Resources/Fonts/CampusHand.ttf`：标题字体；`OFL.txt` 为许可证。
- 工程生成脚本新增资源构建阶段，Info.plist 注册 `UIAppFonts`。
- `CampusArtAssets` 按明确边界隔离三个人物，并缓存用于显示的图像区域，避免预览中相邻图案串入。
