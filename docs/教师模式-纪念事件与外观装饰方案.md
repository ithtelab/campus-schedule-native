# 教师模式、纪念事件与外观装饰方案

日期：2026-11-03。状态：产品方案，尚未实施。

## 产品方向

课间册围绕校园时间安排，支持学生和教师的个人使用。免费、本地优先，无需为了查看课表或使用装饰注册账号。身份决定信息呈现与快捷操作，角色形象和主题由用户独立选择。云端同步是可选能力，需经过签名与跨设备验证后再开放完整承诺。

## 页面安排

- **今日**：当前／下一节课、今天的课程和考试；用户置顶的纪念事件摘要。课程和考试信息排在装饰前面。
- **课表**：周课表、切周、切学期、课程详情。教师模式突出教学班与教室，学生模式突出教室与任课教师。
- **我的**：学期与作息、考试安排、纪念事件、人物与主题、小组件设置、提醒、备份与外观设置。

“我的”是设置页后续承接个性化功能的建议命名，实施时需统一导航与入口，避免逐项叠加多个首页卡片。

## 学生和教师

初次使用可选择学生／教师，支持稍后选择和随时切换。切换不删除数据，不改变已有课程时间；同一用户可以保留多种教学安排。

| 内容 | 学生视角 | 教师视角 |
| --- | --- | --- |
| 课程重点 | 教室、时间、任课教师 | 教室、时间、教学班 |
| 额外信息 | 课程备注、考试座位 | 多个教学班、教学周、授课备注 |
| 一次性安排 | 考试、答辩 | 监考、答疑、公开课 |
| 课前操作 | 查看上课地点与所需材料 | 查看本次授课内容、标记备课情况 |
| 提醒 | 上课、考试及可选下课提醒 | 上课、换教室、监考及答疑提醒 |

教师首版聚焦个人教学安排。备课状态与课程本身分开保存，按某次授课记录，不能点击“已备课”就隐藏或删除课程。教师教务导入须按学校的教师端页面另行适配，学生端解析成功不算教师端已支持；早期可使用手动录入和文件导入。

## 纪念事件：倒数与累计

统一为“纪念事件”，可选择倒数日或累计日。示例分类：考试／考证、生日、入学／毕业、个人纪念日；教师也可自定义公开课、论文截止等事项。

首版字段：名称、日期、倒数／累计、分类图标、提醒、每年重复、是否置顶。可设置提前几天提醒；到期当天显示“就是今天”，过期按用户选择转为累计或归档。计日规则在编辑时说明，避免相差一天。

今日页建议只展示少量用户置顶事件，完整列表在“我的”中管理。纯日期事件不安排常驻灵动岛；有明确开始和结束时间的考试、答辩等，可进入后续实时活动方案。公历优先，农历生日另作日期规则适配与跨年测试后加入。

## 人物与装饰

首批建议四套完整角色：棒球帽女生、耳机男生、手持讲义的教师、校园小猫。用户身份与角色不绑定，教师也能选学生形象或小猫。

- 每套角色提供匹配的完整姿态，服饰、帽子、包、肢体和画面比例保持一致，伸展、拿书等动作不能混入别的角色零件。
- 人物动作由课程／教学状态决定：课前准备、换教室、上课、课间、当天结束；点击触发该状态的短回应，不随机换动作。
- 用户可选择静态或跟随课表互动，减少动态效果时采用静态或短反馈。
- 首批可补约 20 个校园手绘元素：课本、书包、铅笔、夹子、便利贴、黑板、校门、图书馆、纸飞机、树叶等。用于纪念事件分类、卡片角落、封面和空状态。
- 功能按钮、导航和弹窗采用原生组件；手绘元素承担内容识别与装饰。

个性化提供“人物形象”“主题”“装饰密度”“互动效果”四项。密度可关闭、少量、丰富；丰富模式也遵守固定留白和排版区域，不遮挡课程名称、教室、时间或按钮。首版提供预设位置，后续再考虑自由摆放。

## 主题和组件

主题建议三组，保持黑白校园语言：

1. **简洁纸面**：留白为主，少量细线，适合快速读课表。
2. **校园手账**：手写标题、纸张与便签元素，装饰更丰富。
3. **黑板笔记**：深底白线，粉笔风格的局部插画。

主题和浅色／深色是两个独立选择：先选视觉主题，再选跟随系统、浅色或深色。每组主题都需要对应的深浅色资源、对比度与大字体验证。

小组件可独立选择内容与角色，避免在桌面被迫展示 App 内全部装饰。优先提供：下一节课、最近考试、置顶纪念事件。锁屏采用信息更少的紧凑版本；角色点击使用系统支持的交互和短过渡，不能把 App 内持续逐帧播放效果当作组件能力。

### 用户补充确认：纪念日与倒数日的独立组件

纪念日、倒数日都提供独立的桌面与锁屏展示，不要求先置顶到今日页，也不依赖课程组件。用户可以同时添加多个组件，每个组件独立选择事件。

| 位置／尺寸 | 展示内容 |
| --- | --- |
| 桌面小号 | 单个事件的大号天数、名称、日期和小图标 |
| 桌面中号 | 单个事件的天数与日期，旁边展示用户选定的人物或校园插画 |
| 桌面大号 | 多个自选事件，按用户顺序或距离日期排列 |
| 锁屏行内 | 如“距离毕业 120 天”“相识第 365 天” |
| 锁屏圆形 | 精简天数与分类图标 |
| 锁屏矩形 | 事件名称、大号天数和目标日期 |

每个组件可选择倒数／累计、事件、图标，以及适用尺寸下的人物与装饰密度。锁屏优先保证文字清晰，人物与复杂插画主要放在桌面组件。轻点组件进入对应事件详情，事件删除后有明确空状态，不能留下无法打开的旧链接。

按日期计数采用日历日规则，到期当天显示“就是今天”；每年重复事件跨年后指向下一次日期。测试覆盖跨午夜、跨年、闰日、系统时区变化与删除事件后的组件刷新。展示和更新行为仍需实际系统宿主验收，不承诺持续逐秒动画。此补充属于已确认的产品范围，尚未实现。

## 数据与架构

课程、考试、纪念事件、教学班、某次授课的备课状态、外观偏好分别建模。重复课程仍使用现有课程规则；一次性考试／监考／答疑不能硬塞进每周循环。

个人数据本地保存，外观偏好不随切换身份或学期丢失。导出格式使用版本与可选字段迁移，旧备份缺少新字段时可读取；提醒和组件读取经过校验的独立快照。人物与装饰资源通过统一 DesignSystem 选择与排版，不分散写在各业务页面。

## 实施顺序与验收

1. 先完成现有数据保护、导入、考试编辑、外观和组件交互修复的编译与真机验收。
2. 加入纪念事件基础功能、置顶展示及其桌面／锁屏组件，同时建立人物和装饰选择入口。
3. 加入教师身份呈现、教学班、监考／答疑和按次备课状态，验证切换身份不改写既有课程。
4. 扩充完整角色动作与主题资源，再做更多组件样式与较复杂的摆放方式。

每批都检查：数据重启不丢、取消不保存、提醒开关与权限一致、长标题与大字体可读、深浅色资源清晰、人物身份与动作逻辑一致、关闭装饰后完整可用。

考试专属系统提醒、教师模式、纪念事件和装饰库当前均属于规划。已有实时活动后台自动结束缺口不会因为增加新事件而自动解决，需独立验收。
