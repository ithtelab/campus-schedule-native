# 系统组件打开本次课程（2026-11-03）

用户要求小组件、锁屏与灵动岛进入独立页面，只清晰显示所点课程的本次安排，不打开编辑页。

## 改动

- 新增 `CourseNowView`，只展示课程名称、地点、日期、起止时间、状态及教师；没有编辑字段、提醒开关、调课或删除操作。App 内的课程详情和编辑入口保留。
- 桌面与锁屏课程组件、锁屏实时活动、灵动岛统一携带课程、学期及课程实例的深链。旧实时活动可从旧实例键识别课程，无法识别时回到今日页。
- 明确携带实例 ID 时，即使该节已结束，也保持查看这节课；实例已移除则显示更新提示，不自动改成另一节。旧链接没有实例 ID 时才定位该课程最近待上的安排。
- 外部课程链接重建弹层承载视图，保留同一份课表状态，清除之前打开的编辑弹层；重复打开链接可切换课程。只读查看不修改课程数据。
- 演示版使用稳定的演示学期标识，避免重启生成随机标识导致新组件链接失效。已有旧版随机学期链接仍可能需要组件刷新后再点，不回退到错误学期。
