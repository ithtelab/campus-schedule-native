## 实时活动系统检查

构建 [d662236b-0bcd-45b8-a684-f51a5a000026](https://expo.dev/accounts/ithte/projects/campus-schedule-native/builds/d662236b-0bcd-45b8-a684-f51a5a000026) 已完成，12 项测试及编译通过，并运行额外系统检查。

| 系统检查 | 实际结果 | 判定 |
| --- | --- | --- |
| ActivityKit 创建请求 | `PASS: Live Activity created` | 仅确认请求后能枚举到活动，不能等同于 UI 已显示 |
| APP 退后台后的画面 | `activity-in-background.png` 中是系统设置页，未确认看到灵动岛 | 展示未验证通过；原因尚未定位，不武断归因于签名或模拟器 |
| 超过测试课程结束时间 | `STILL_PRESENT_AFTER_END` | 仍能枚举到活动，不能认为到点已自动清理 |
| 审计后的清理 | 显式调用活动结束 API | 仅清理本次云端测试，不代表后台自动结束实现完成 |

结果文件位于 `screenshots/activity-start-test.txt`、`activity-end-audit.txt`，图片位于 `activity-in-background.png` 和 `activity-after-end-time.png`。

检查使用独立测试环境变量：创建一堂几秒后开始、20 秒后结束的课程活动，切换系统设置使 APP 退到后台，记录系统画面；到课结束后检查活动是否仍存在，再显式清理测试活动。不修改真实课程，不把“请求返回成功”直接等同于“已显示灵动岛”。

本系统检查故意只测试请求与系统到点行为，未启动应用内的前台协调计时器，也没有服务器结束推送。因此它说明 `staleDate`/倒计时不能直接当作系统定时结束保证，不是对整个生产协调流程的完整验收。

## 仍不能替代的验收

- 正式签名后 App Group 跨进程数据共享、桌面/锁屏真实添加和刷新。
- 真机通知权限、声音、专注模式、锁屏送达。
- Live Activity 课前计划启动、课前到课中的状态变化、完整后台自动下课结束、下一节衔接与用户移除行为。
- 用户设备的电量、性能与系统调度表现。

云端状态和真机状态分开记录；没有证据的项目不能标 PASS。
